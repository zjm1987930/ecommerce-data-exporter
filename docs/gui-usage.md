# GUI 使用说明

## 日常导出

推荐所有日常导出都从 GUI 执行。

启动：

```powershell
.\run.ps1
```

基本流程：

1. 选择开始日期和结束日期。
2. 勾选需要执行的店铺。
3. 勾选需要导出的数据类型。
4. 点击“开始生成任务”。

如果只想验证接口或查询条件，不想保存导出文件，可以在“工具箱”中勾选“试运行：只查询/只生成下载地址，不保存导出文件”。

当前已接入真实自动化的数据类型：

- 退货数据
- 消费者负向体验扣款数据
- 延迟发货数据
- 客服绩效数据
- 抖音保证金数据

GUI 顶部可选择平台。拼多多店铺和拼多多数据类型只在选择“拼多多”时显示；抖音店铺和保证金数据只在选择“抖音”时显示。

## 执行顺序

GUI 按串行队列执行，不会并发打开多个自动化窗口。

多店铺、多数据类型同时勾选时，执行顺序为：

```text
店铺A - 退货
店铺A - 负向体验
店铺A - 延迟发货
店铺A - 客服绩效
店铺B - 退货
店铺B - 负向体验
店铺B - 延迟发货
店铺B - 客服绩效
...
```

## 补登录

补登录统一使用 GUI 里的“补登录选中店铺”按钮。

单店补登录：

1. 只勾选需要补登录的店铺。
2. 点击“补登录选中店铺”。
3. 在打开的普通 Edge 中完成登录，确认进入后台。
4. 关闭这个普通 Edge 窗口。
5. 回 GUI 选择该店铺和失败的数据类型补跑。

多店铺补登录：

1. 勾选多个店铺，或全选店铺。
2. 点击“补登录选中店铺”。
3. GUI 每次只打开一个店铺的普通 Edge 登录窗口。
4. 完成当前店铺登录并关闭 Edge 后，回 GUI 点击“我已完成人工操作，继续”，再打开下一个店铺。
5. 全部补登录完成后，再回 GUI 执行导出任务。

不要在自动化导出窗口里处理新登录。登录失效时先用 GUI 补登录，再单店补跑失败项。

## 人工介入

如果日志提示需要人工介入，例如手动选择日期或手动进入页面：

1. 在打开的自动化窗口中完成对应操作。
2. 回 GUI 点击“我已完成人工操作，继续”。

## 终止任务

如果任务启动参数选错、页面卡住或需要中止，点击“终止任务”。

终止是安全停止：当前浏览器步骤结束后停止后续店铺和数据类型，不会强杀 Edge profile。

## 输出规则

输出目录按“数据类型 -> 日期范围 -> 店铺”组织：

```text
原始数据/
  数据类型/
    YYYYMMDD-YYYYMMDD/
      店铺/
        数据文件
```

负向体验是多店铺 sheet 工作簿，放在：

```text
原始数据/消费者负向体验扣款数据/YYYYMMDD-YYYYMMDD/
```

退货数据下载后按固定文件名保存：

```text
YYYYMMDD-YYYYMMDD + 店铺短名 + 退货.xlsx
```

例如：

```text
20260501-20260515拼多多大雁书籍退货.xlsx
```

延迟发货会保留平台原始 XLSX，并整合为一个包含 3 个 sheet 的工作簿：

1. 延迟发货
2. 缺货
3. 虚假发货/虚假轨迹

负向体验会按店铺 sheet 生成一个月度工作簿。单店补跑时只替换本次参与店铺的 sheet，尽量保留其他已成功店铺的数据。

客服绩效数据会下载平台原始 XLS 文件，并按固定文件名保存：

```text
YYYYMMDD-YYYYMMDD + 店铺短名 + 客服绩效.xls
```

例如：

```text
20260501-20260515拼多多大雁书籍客服绩效.xls
```

客服绩效最多只能选择近 60 天数据。如果开始日期超过平台可选范围，任务会标记失败并提示缩短日期范围，不会自动裁剪日期。

抖音保证金数据会导出体验保证金 TAB 的交易流水 CSV：

```text
YYYYMMDD-YYYYMMDD + 店铺短名 + 保证金.csv
```

抖音 13 家店铺共用同一个登录状态目录：

```text
browser_profiles/douyin/douyin_default/
```

执行多家抖音店铺时，工具会在抖音后台右上角自动切换店铺，然后逐店查询和下载保证金 CSV。

## 工具箱

工具箱包含：

- 试运行：支持退货、延迟发货、客服绩效只查询或只生成下载地址，不保存导出文件；负向体验暂不写文件。
- 生成调试命令：按当前选中第一个店铺和日期范围生成带中文说明的常用 PowerShell 命令，包括补登录、单店验证、客服绩效接口监听、退货接口监听。
- 添加店铺配置：在一个完整表单中填写店铺 ID、店铺完整名称、店铺短名，点击保存后写入 `config/shops.json`，添加后重启 GUI 生效。
- 删除店铺配置：从 `config/shops.json` 删除选中店铺；只删除配置，不删除浏览器登录状态或已导出文件。
- 清理原始数据目录：删除 `原始数据` 下导出文件和日志，操作前会二次确认。
